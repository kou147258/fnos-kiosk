v0.1.13: 画面适配三种模式 + Scale 13 档

## 用户反馈
「屏幕显示能自适应不？目前好像不能自适应显示，部分显示超出显示器了。
 缩放挡位也只有3」

## 修复

### 1. display_fit 三种模式

之前默认 cover（填满 fb + 裁切）。当 chromium 截图 1920x1080
填到 fb0 1024x768 时，左右各被裁掉 170px——内容溢出屏外。

新增 display_fit 配置：
- contain (默认，整页可见，多余区域填黑边) — 推荐
- cover (铺满 fb，等比放大裁切) — 适合背景图
- stretch (强制拉伸到 fb 尺寸，可能变形)

主循环里热加载 display_fit，不需要重启 fb_render。

### 2. Scale 13 档

之前只有 1.0 / 1.25 / 1.5 / 2.0 四档。扩展到：
0.5 / 0.67 / 0.75 / 0.85 / 1.0 / 1.15 / 1.25 / 1.5 / 1.75
/ 2.0 / 2.5 / 3.0 / 4.0

适合各种 DPI 的 NAS 副屏。

## 改动文件

- app/bin/fb_render.py — _render_background 加 fit_mode 参数
  (cover/contain/stretch)
- app/bin/dash_config.py — display_fit 白名单 + 默认 contain
- app/web/settings.html — 画面适配模式 seg + 13 档 Scale
- app/web/assets/settings.js — seg-fit 点击 + display_fit 回填
