v0.1.55 (2026-09-21)

修复：URL 页面 horizontal squish + 部分行被裁切

问题：v0.1.45–v0.1.54 把 URL 页面 viewport 强制设为 match_dashboard (1365×768 16:9)，
导致在 4:3 fb0 (1024×768) 上：
- dashboard 被 0.75× 横压（三列卡变窄，比例失衡）
- 部分行被 viewport 底边裁切（温度、系统信息那两张卡看不见）

解决：v0.1.55 改回 match_fb (1024×768) — fb 物理分辨率
- Chromium viewport = 1024×768
- Dashboard 自然排版，6 张卡完整可见，无横压
- 用户缩放滑块 50%–300% 继续只缩 dashboard 内部内容 (transform: scale)，
  URL viewport 本身不变 ——「像浏览器 Ctrl +/- 那样调整内部内容」

- app/bin/fb_render.py     (2 处 match_dashboard → match_fb，line 815 + 1059)
- manifest                 (version=0.1.55)
