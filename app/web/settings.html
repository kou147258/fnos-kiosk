🔐 登录态管理

        
Cookies / localStorage / 密码 自动保存到 —。重启 FPK / Chromium 后自动恢复登录态。

        

          
          
        

        
…

        

          首次登录流程（三种方式任选其一）：


          A. 远程调试连接（推荐）

          1. 在 PC 浏览器打开 chrome://inspect/#devices

          2. 勾选「Discover network targets」→ 「Configure」→ 加 localhost:9223

          3. 用 SSH 隧道把 NAS 的 9223 转到你 PC：

             ssh -L 9223:127.0.0.1:9223 user@nas-ip

          4. chrome://inspect 里会出现 kiosk 的 headless Chromium，点击「inspect」→ 在 DevTools 里手动登录

          5. 登录完成即可关闭 DevTools，kiosk 自动接管


          B. SSH + 非 headless 登录

          1. SSH 进 NAS

          2. 停掉 kiosk 的 fb_render（避免锁）：/var/apps/com.fnos.kiosk/cmd/main stop

          3. 用同一个 profile 启 Chromium（假设 DISPLAY 已就绪）：

             chromium --user-data-dir=/var/apps/com.fnos.kiosk/var/chromium-profile --no-sandbox 

          4. 登录完成后关 Chromium，重新启 fb_render：

             /var/apps/com.fnos.kiosk/cmd/main start


          C. SSH + Xvfb 无显示登录（需要 Xvfb + xdotool）

          xvfb-run -a chromium --user-data-dir=/var/apps/com.fnos.kiosk/var/chromium-profile --no-sandbox 

          Chromium 会跑在虚拟显示里，登录态照旧写盘。复杂 2FA 不推荐。
